# v0.1.0 - Initial Public Release

Date: 2026-04-15

Use the copy below for the first GitHub Release.

## Release Title

`v0.1.0 - Initial Public Release`

## Release Body

```md
This is the first public release of the `midjourney-api` examples repository.

It gives developers a clean starting point for integrating Midjourney API into real applications with Node.js and Python.

What's included:

- Node.js examples for submitting jobs, polling status, and receiving webhook callbacks
- Python examples for the same core workflow
- Framework webhook examples with Express and FastAPI
- A repo setup that is ready for public use, including `README`, `.env.example`, `LICENSE`, `CONTRIBUTING`, issue templates, a PR template, and CI

Repository highlights:

- Async workflow with `taskId`
- Polling and webhook patterns
- Minimal setup for local testing
- Docs and landing pages for getting started, pricing, and webhook integration

Start here:

- Getting started: https://www.midjourney-api.com/getting-started
- Webhook guide: https://www.midjourney-api.com/webhook
- Pricing: https://www.midjourney-api.com/pricing

This release is focused on making the repository immediately useful for developers who want to test the API quickly and build a reliable async image workflow.
```
