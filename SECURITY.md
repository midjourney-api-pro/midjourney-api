# Security Policy

## Reporting A Vulnerability

If you believe you have found a security issue, please avoid opening a public GitHub issue.

Use one of these paths instead:

- contact the team through https://www.midjourney-api.com/
- use the support or contact channel in the dashboard if you are already a customer

When possible, include:

- a short summary of the issue
- affected files or example paths
- reproduction steps
- potential impact

We will review the report and follow up privately.
